# Token Launch Radar

- **Board.** Conditional launch values for protocols recording no token and watchlist entries. Offline recompute checks ranks, values and farm steps. Value bars and P10–P90 bands share a log scale.
- **Card.** Waterfall, nearest traded families, rank sensitivity, launch clock and costed farm steps.
- **Method.** Fit, validation, ablation, interval coverage, clock, house rule and dated assumptions.
- **Census.** Every protocol, filterable by status, with its classification reason.
- **Farm planner.** Set cash, hours and chains. Sliders update verdicts and the portfolio. Reset restores board defaults.
